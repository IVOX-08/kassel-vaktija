# How to put the privacy policy online (free, ~5 minutes)

You need a free GitHub account: https://github.com/signup
Once you have it, do this in the browser — no coding:

1. Go to https://github.com/new
2. **Repository name:** `kassel-vaktija`  → set it to **Public** → click **Create repository**.
3. On the new repo page click **“uploading an existing file”**.
   Drag in the file **`index.html`** from this folder (`docs/play/privacy-site/`). Click **Commit changes**.
4. Go to the repo’s **Settings → Pages**.
   Under **Source** choose **Deploy from a branch**, branch **main**, folder **/ (root)** → **Save**.
5. Wait ~1 minute, then reload. GitHub shows your live link, e.g.:
   **`https://YOUR-USERNAME.github.io/kassel-vaktija/`**

That link is your **privacy policy URL**. Paste it in Play Console in two places:
- **Store listing → Privacy policy**
- **App content → Data safety** (when asked for the policy link)

To update the text later: open `index.html` in the repo, click the pencil ✎, edit, commit. The live page updates automatically.
